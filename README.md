# SOP-work

方便快速编写 SOP 的工具。保留既有表格版式，支持公司名称与 Logo 设置、固定内容沿用、正文页任意排序、自动分页和页码更新、项目导入导出、可编辑 Word 导出及 PDF 预览。浏览器版和 Windows 桌面版使用同一份编辑代码。

## 在 SOP-work 云端环境继续开发

选择已配置的 **SOP-work** 环境和本仓库 `main` 分支。仓库根目录使用 Node.js 22 及以上版本；浏览器编辑器没有需要安装的运行依赖。

```sh
npm test
npm run dev -- --host 0.0.0.0 --port 4173
```

默认页面为 `http://localhost:4173`。如云端环境支持端口预览，打开 4173 端口即可。环境需要填写初始化命令时可使用 `bash scripts/cloud-setup.sh`，只执行源码与通用资源检查。

本次迁入的是通用工具源码，项目默认公司信息为空。原公司 SOP、Logo、现场照片、测试项目、本地缓存和旧安装包保留在原电脑，未上传仓库。已有内容通过工具的“保存项目”和“导入”继续使用。

## 本地使用与编辑

2026-10-30 增加图文对象画布和流程图画布。工序中的照片、图外文字框与箭头可独立摆放；流程图支持节点、连接和分支标签。导入封面、履历和流程图默认保留原稿，编辑副本与原稿可切换。兼容封面的字段可局部替换，复杂原稿转换为画布后仍需人工核对。

`object-workspace.js` 负责对象模型、SVG 预览和画布交互。按工序生成编辑画布最多 24 个节点；原有自动流程多页模式保留。新增对象检查已纳入 `npm test`。本次实际 Word 输出已做结构及 WPS 渲染检查，但受浏览器工具访问策略限制，未执行浏览器交互和打印冒烟测试；不能以模型测试代替 UI 验收。

直接打开 `outputs/SOP工作台/index.html`，或执行上面的预览命令。主要文件：

| 路径 | 用途 |
| --- | --- |
| `outputs/SOP工作台/app.js` | 编写、固定沿用、分页、排序、预览和本地保存 |
| `outputs/SOP工作台/word.js` | DOCX 导入、原生文字与表格导出、公司 Logo |
| `outputs/SOP工作台/native-shapes.js` | 独立可编辑的箭头、圈选、文字框和流程图 |
| `outputs/SOP工作台/style.css` | 编辑器界面及 SOP 打印版式 |
| `outputs/SOP工作台/assets.js` | 通用空白项目与版式骨架 |
| `desktop/` | Windows 桌面窗口、保存对话框及 PDF 导出 |
| `scripts/` | 跨平台预览和云端检查 |

在“固定格式”中修改公司名称、上传/移除 Logo、调整保密文字及页脚，预览和导出同步更新。新建项目沿用当前设置。正文页可拖动或通过“移动到…”移动、交换；封面、修改履历和流程图均可编辑并任意排序。

Word 中的文字、表格、图片、标注和流程图保持可编辑；PDF 用于定稿浏览。编辑后约 400ms 自动保存本机恢复缓存。桌面版“保存”/ Ctrl+S 首次选择 `.sop.json` 路径，之后更新当前文件；“另存为”/ Ctrl+Shift+S 创建另一份项目并切换关联。打开项目后保存回该文件；导入 Word 始终另存为项目，不覆盖 Word。新建、打开或关闭前可选择保存、不保存或取消；画布与标注需先在各自窗口提交。文件写入使用同目录临时文件后替换，检测外部修改时询问覆盖。支持 File System Access API 的浏览器具有同样的保存/打开功能；其他浏览器仅下载副本，状态不会冒充当前文件已保存。缓存和文件关联分别存储，恢复时核对关联标识，避免覆盖错误项目。项目文件、恢复缓存都仅在本机，不会自动同步到云端。

## 验证

`npm test` 无需额外依赖，检查 JavaScript 语法、通用资源、版式中的原稿信息清理和页面脚本引用。

涉及内容、排序或 Word 导出的改动，可安装 Playwright 后运行浏览器冒烟测试：

```sh
npm install --no-save playwright@1.62.1

```

也可通过 `SOP_PLAYWRIGHT_MODULE` 指向环境已有的 Playwright 模块，通过 `SOP_TEST_BROWSER` 指定已有浏览器程序。测试使用独立浏览器上下文，覆盖公司/Logo、正文排序与页码、Word 往返和自动保存。

## Windows 软件打包

仓库 Actions 中提供手动触发的 **Build Windows app** 工作流，在 Windows 构建器上生成安装 EXE 和免安装 ZIP；完成后从该次运行的 `SOPStudio-Windows-x64` artifact 下载。工作流不会自动发布 Release，不包含真实 SOP 内容。

在普通 Windows 开发机上也可以执行：

```sh
cd desktop
pnpm install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
python prepare-renderer.py
node node_modules/electron-builder/out/cli/cli.js --win nsis zip --x64 --publish never
```

使用 pnpm 11.25.0、Node.js 24 和 Python 3.13。构建输出在 `outputs/软件安装包/`，运行软件无需另装这些开发工具。

`desktop/build-windows.py` 与根目录“打包桌面软件.cmd”保留原电脑上的手工构建路径，需要原本地 `work/` 内的公开运行时及 NSIS 工具缓存；新的云端或普通 Windows 检出请使用上述工作流。当前未配置数字签名证书。

## 原稿保持模式与标注预设

导入兼容 DOCX 后保留原稿的文字、图片和原生标注。浏览器按工序表格展示；原稿的表格、段落和浮动锚点随项目保留；普通 Word 导出改为固定行高单页模板，不再维持原稿的自动溢出分页。浏览器表格数量不代表 Word 的物理页数。修改正文或配图后会按工作台规则重新编排，应重新核对导出结果。旧版已经丢失的内容需要重新导入原 Word 才能恢复。

图片标注支持文字/线条颜色、背景颜色预设、透明背景、字号、矩形与直线。新增标注导出为独立可编辑形状，原照片不合并进标注。

## 工序固定单页，手动排版

每个工序保持一页，不自动缩小文字、图片或画布，也不因内容或物料过多生成续页。字号、字间距由用户手动调整。超框内容在编辑数据和导出文档中保留，显示时可能遮挡或被框体裁切，请调整内容、位置和图片尺寸。物料超出 8 行时在末格保留其余条目，不另增页。可主动新增工序页拆分内容；原始 SOP、照片及项目文件不被覆盖。普通 Word 导出采用固定行高模板，导入原稿仍随项目保留；不能再以原稿字节不变来断言新导出的固定单页布局。`npm run test:manual-page` 覆盖超量图文、物料、旧项目排版标志、字号不缩放及回导。

## 全篇页面编辑与工序页码

点击文档结构中的封面、修改履历、流程图即可修改其内容。封面字段和标题可编辑；履历条目可增删改；流程图支持自动生成和手动编辑节点。所有页面均可拖动、上下移动、移动到指定位置或交换，预览和 Word/PDF 沿用当前顺序。只有工序页显示并参与“第几页／共几页”的统计，封面、履历和流程图即使穿插在工序页中也不计入。修改内容与页序保存在项目文件和本地自动保存中。

## 2026-10-30 新模板

工序页使用新版宽图文区、8 行物料、两列检查频次与右下签字区。`template-v2.js` 提供对应预览。Word 保留原表格网格和行高；页眉使用 PAGE 与嵌套 NUMPAGES 动态域，仅工序页参与计数。原有封面/履历/流程图编辑、全篇排序、图文标注和单页自适应功能保留。

## 画布角度与颜色

选中箭头或直线后，拖动起点和终点圆点可调整任意角度；右侧可输入端点、角度和长度，0°向右、90°向下。项目保存与 Word 导出沿用同一端点几何，旧版 flipX/flipY 箭头保持兼容。画布工具栏提供矩形、椭圆、菱形和箭头；文字在形状属性中填写，旧文字框可继续编辑。

图文画布和原图片标注共用主题颜色、标准颜色、最近使用和自定义十六进制色板；最近颜色仅存于本机。左侧只显示“新增工序页”，内容过多也不自动续页。页面、目录和属性面板在视口内分别滚动，小屏幕按上下区域显示。

新增组件为 `color-picker.js` 与 `workspace-controls.css`。桌面准备脚本会同时复制；`npm test` 包含角度、端点兼容、色板及入口检查。Word 保留文字、形状、照片和连接线的独立对象，照片可独立移动、缩放和更换。

## 工序页独立签字信息

右侧当前页工作区可独立填写编制、审核、批准的姓名及各自日期，以及工序页版本号。它们与封面文档信息分开；旧项目首次加载时保留原显示值。“设为固定沿用”锁定当前页这一组字段，新增工序自动复制，已有其他页不受影响。解除固定后可单独修改。预览和 Word 中的签字栏均保持水平、垂直居中。

## 桌面软件自动更新（0.4.1 起）

左下角“软件更新”和菜单“帮助 → 检查软件更新”打开更新面板。默认启动后 10 秒自动检查，此后每 6 小时复查；可关闭自动检查。联网只查询版本及下载公开程序，不上传 SOP 内容。检查失败不影响离线编辑。

日常更新下载约几百 KB 的 ASAR 程序包，不必下载完整 ZIP/安装 EXE。发现新版本后由用户点击下载；显示进度并可取消、重试。下载后验证 Ed25519 发布签名、SHA256、大小、平台、运行环境和程序包版本；不符合则拒绝安装。更换 Electron 运行环境的版本会提示到发布页下载安装 EXE。点击“重启并安装”仍经过现有项目保存/放弃/取消流程；取消时不退出。退出后独立更新助手替换程序，保留 `resources/app.asar.previous`，写入失败保留原程序。更新不修改项目文件和恢复缓存。软件安装目录不可写时会报告失败，不会自行提权。

下载默认使用 `yhanxi/SOP-work-releases` 的公开 GitHub Releases。主进程使用 Electron 网络栈，可遵循系统代理。无代理且 GitHub 无法访问时，需要配置可访问的自有 HTTPS 下载目录；仅缩小体积不能解决网络被阻断的问题。未预置公共代理或不受控镜像。

### 配置备用下载目录

在更新面板展开“下载源设置”，填写如 `https://downloads.example.com/sop`，点击“应用下载设置”。配置后优先从该目录读取 `latest.json` 和同名程序包，失败时回退 GitHub；手动检查也会比较 GitHub 的有效新版本。备用地址不可带账号、密码或查询参数。设置仅保存在本机，不随项目分享。所有来源的更新清单必须通过软件内置公钥的签名校验。

站点需要托管最新发布的 `latest.json`（与 `SOP-update.json` 内容相同）和 `SOPStudio-VERSION-app.asar`，用对应版本完整替换后再刷新 latest.json。可将公开更新文件放在自己的静态站点、对象存储或 CDN；软件本身不绑定付费服务。

### 发布后续更新

保留同一个更新签名私钥，私钥不在仓库、安装包或 Release 中。发布机器须安全备份该私钥；丢失后不能向已有软件发布兼容的可信更新。软件只附带 `desktop/update-public.pem`。签名脚本会验证私钥与内置公钥相匹配。

```sh
node desktop/make-update.cjs PATH_TO_APP_ASAR PATH_TO_PRIVATE_PEM OUTPUT_DIRECTORY
```

将输出的 `SOP-update.json`、`SOPStudio-VERSION-app.asar`、安装 EXE 和 ZIP 上传至公开下载仓库 `yhanxi/SOP-work-releases` 的相应 GitHub Release，并在准备完成后发布 Release。备用目录额外提供相同内容的 `latest.json`。请先在独立运行时验证更新和项目保存，再发布签名清单。更换公钥必须通过已有可信密钥签名的版本或手动安装完成。

`npm test` 包含签名/篡改、校验、版本比较、备用源回退、断网、取消重试及原子替换备份测试。桌面实际验证还覆盖保存取消阻止安装、真实 Node 更新助手替换、重开版本号和未保存内容恢复。0.4.0 的更新面板沿用工作台青灰配色、紧凑控件与可折叠下载设置，并验证常见状态和小窗口布局。

源码仓库 `yhanxi/SOP-work` 保持私有；更新下载使用独立公开仓库 https://github.com/yhanxi/SOP-work-releases ，只放通用软件包、签名清单和校验文件。软件更新不需要源码仓库权限，也不附带 GitHub 令牌。0.4.1 修正了私有仓库匿名检查返回 404 的问题。

## 0.4.2 画布端点吸附与鲜艳色板

对象属性栏移除横纵坐标、宽高以及箭头起终点 XY 输入；拖动、四角缩放、字号、角度和长度仍可使用。内部位置与尺寸格式保持兼容。主题色板包含鲜艳红、橙、黄、绿、青、蓝、紫、粉以及由亮到深的梯度；标准色、最近使用和自定义颜色保留，旧项目已有颜色不被替换。

拖动箭头或直线的任一端点，进入约 10 个屏幕像素范围时吸附到图片/矩形角点及边中点、菱形实际顶点及斜边中点，也支持其他箭头/直线的端点和中点。超出范围立即恢复自由定位；按住 Alt 暂时关闭吸附。范围按屏幕像素计算，画布缩放时手感一致。吸附时显示青色锚点提示，释放后消失；提示不会保存或导出。箭头、直线端点吸附后保存目标与吸附点，移动或缩放目标时自动跟随；拖离吸附范围或按 Alt 拖动端点可解除。两端可分别连接，关系随项目保存和重新导入恢复。旧版本箭头需重新吸附端点后建立关系。整体移动箭头、手动改变角度/长度或翻转会解除其连接；删除目标保留箭头当前位置，复制箭头生成自由副本，撤销可恢复连接。循环连接不建立依赖。Word 导出保留当前位置和独立可编辑形状。流程图原有“连接两个节点”的跟随连线继续保留。

`npm run test:canvas` 验证真实鼠标拖动、近距/超距/Alt、撤销、F2/双击文字编辑以及可编辑 Word 往返；支持和 `test:browser` 相同的 Playwright/浏览器环境变量。签名更新发布脚本的可选第四个参数可传入 UTF-8 更新说明文件。

## 拖拽绘制与样式记忆

选中矩形、椭圆、菱形或箭头工具后，在画布按下并拖动，松开完成添加；支持反方向绘制，Esc 取消，单击而不拖动不会添加。每种元素分别记住最后使用的字号、文字/线条颜色、填充和线条粗细，保存在本机，重开软件仍沿用，不会改动已有对象。属性栏“线条粗细”支持 0.5–20，连接线同样可调；预览、项目和独立可编辑 Word 形状同步。`npm run test:drawing` 验证真实拖拽、取消、撤销、跨刷新样式记忆及 Word 往返。

## 操作步骤与技术要求文字格式

操作步骤、工艺技术要求共用一组正文格式：字号（6–36 磅）和字间距（-1–10 磅，0 为标准）。输入区、预览与 Word 同步。“固定格式”只锁定并继承这组格式；两处“固定文字”分别锁定并继承各自内容，可独立启用和解除。仅固定格式时，新增工序文字保持空白可编辑；仅固定文字不继承格式。旧项目已有不同格式会保留，调整共用控件后统一两处。内容固定单页，不自动缩放或续页。`npm run test:text-format` 验证共用格式、独立固定、继承、缓存恢复及 Word 输出。

`npm run test:connections` 验证真实鼠标连接、移动和缩放跟随、两端独立、解除/重连、删除/撤销、拖拽新建及 Word 项目往返；`npm test` 包含依赖链、循环和损坏引用检查。
